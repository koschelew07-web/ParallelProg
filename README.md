## 📌 Цель работы
Изучение принципов параллельных вычислений и освоение инструментов
для реализации многопоточных и многопроцессных программ.

## 🛠 Задачи
1. Ознакомиться с теоретическим материалом по параллельным вычислениям.
2. Реализовать программу, использующую параллелизм.
3. Провести замеры производительности последовательной и параллельной версий.
4. Сравнить результаты и сделать выводы.
